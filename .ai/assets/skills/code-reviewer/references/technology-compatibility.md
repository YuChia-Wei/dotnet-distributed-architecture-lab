permission to overwrite them. Regenerate target-effective rule state through
the owning upgrade process after accepted catalog changes. Preserve rule IDs
and normative statements; this change relocates derived consumers.

by editing this source. Candidate package and upgrade evidence are reported
separately from an actual downstream upgrade.
