# Target AI context placement

The target-owned placement policy is [AI-CONTEXT-BOUNDARY.md](../.dev/standards/AI-CONTEXT-BOUNDARY.md) with the [language policy](../.dev/standards/AI-CONTEXT-LANGUAGE-POLICY.md). Selected managed packages and knowledge belong under `.ai/core/`; desired selection and explicit project settings belong under `.ai/custom/`; the lock belongs to the installer. Runtime entries belong under `.agents/skills/` and `.claude/skills/`.

Project facts, effective rules, requirements, specifications, operations and workflow records belong under `.dev/`. Do not promote a package example or generated index to target authority. README files explain a directory; indexes provide navigation.
