# Durable Assessments

This directory stores durable audits, large code reviews, architecture
assessments, and similar evidence-backed observations that may or may not become
future work.

Use [INDEX.MD](INDEX.MD) to discover assessments. Existing records retain their
recorded identity, format, evidence and original scope. For a newly selected
assessment, follow [AGENTS.md](../../AGENTS.md), the authorized task and the selected
owning skill's actual output contract. Record the checks performed and their
limits; a saved report does not establish a validator or runtime acceptance pass.

Assessments are not workflows and do not authorize remediation. Track selected
findings through an authorized follow-up using its chosen skill and destination.
