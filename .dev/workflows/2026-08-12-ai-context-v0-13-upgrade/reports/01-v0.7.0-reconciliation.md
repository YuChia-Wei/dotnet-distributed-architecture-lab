## Independent Blocked Audit

An independent `gpt-5.6-sol` / `max` read-only audit stopped provenance
finalization for two concrete reasons:

1. Twelve operations (`0006` through `0014`, `0021`, `0025`, and `0026`) were
   classified as reconcile only because Windows CRLF bytes did not match the
   LF package base. After removing carriage returns, every target file matched
   v0.6 exactly while differing from v0.7. Treating all of these as intentional
   target semantics would have silently skipped new enforcement.
2. The incoming workflow validator reported ten errors: each of the five active
   `AICU-*` task records lacked `model` and `reasoning_effort`. The incoming Git
   validator also rejected bootstrap commit `70a5ae5` because the package's
   source-repository effective time predated that target commit.

This is retained as an upstream feedback case: raw-byte base comparison creates
false reconciliation on Windows when the target checkout normalizes LF assets
to CRLF, and validation with the installed pre-upgrade scripts can produce a
false-positive gate.
