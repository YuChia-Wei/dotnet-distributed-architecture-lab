## Residual Lifecycle Defect

The direct v0.15.x recorder still retains the same high-level prohibition on
unrelated post-apply target changes. That guard is correct for ordinary drift,
but it does not distinguish digest-bound remediation required to make target
validation pass.

The current v0.14 edge demonstrates the conflict:

1. The package-native downstream projection references removed/source-only
   checks, so target validation requires a version-pinned target overlay.
2. The exact target validation passed with that overlay and produced a canonical
   receipt candidate.
3. The recorder rejected the overlay, assessment, report, and ignore-policy
   correction as unrelated post-apply changes before it would bind the receipt.
4. Hiding or stashing those changes only for receipt recording would bypass the
   fail-closed recovery intent and is not an acceptable completion route.
