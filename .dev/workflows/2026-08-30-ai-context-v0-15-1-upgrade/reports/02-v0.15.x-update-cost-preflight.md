## Residual Lifecycle Findings

The direct v0.15.x recorder still requires all target-owned validation and audit
preconditions to exist before planning, and current HEAD must remain equal to
the sealed starting commit until terminal finalization. A conventional commit
checkpoint between apply and receipt binding invalidates the transaction.

Measured v0.15.0 recovery also exposed a Windows executable-mode replay issue:

1. Each rollback restored all 50 paths and reached `rolled-back`.
2. After each executable shell path was restored, the first process stopped
   after durable progress but before journal compaction.
3. Repeating the same rollback command replayed the exact progress and continued
   without manual file repair.
4. The behavior is recoverable but should be tracked as an upstream defect.
