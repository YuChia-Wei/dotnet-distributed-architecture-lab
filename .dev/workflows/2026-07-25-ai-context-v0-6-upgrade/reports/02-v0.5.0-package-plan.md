## Decision Rules

- Framework-owned scripts, validators, canonical skill metadata, and thin
  runtime wrappers: adopt incoming semantics unless a proven target-specific
  adjustment remains necessary.
- Target standards and human guides: three-way merge the framework change while
  retaining adopted local architecture and repository facts.
- Backlog and root repository attributes: preserve target authority and add only
  non-conflicting framework requirements.
- Removed upstream tests: remove only when their replacement coverage is present
  in the incoming package.
