實驗室部署與責任邊界
1. 僅模擬：固定範例沒有進上游
2. WireMock hybrid：高優先序範例與廣域代理
3. Microcks hybrid：已知 operation 的範例與 fallback
4. 模式切換與讀回：控制成功不等於流量正確
5. 供應商已提交、呼叫端逾時：保留原 key 協調
6. 實際收貨才入庫：兩端各自保證冪等
7. 銷售訂單另走庫存保留
